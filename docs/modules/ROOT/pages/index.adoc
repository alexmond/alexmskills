= alexmskills — Claude Code Skills Marketplace
:description: A curated Claude Code plugin marketplace of reusable, self-improving skills and agents — each an independently versioned plugin you install and update on demand.
:navtitle: Overview

`alexmskills` is a curated https://code.claude.com[Claude Code] **plugin marketplace** of reusable,
self-improving skills and agents. Each skill is packaged as an **independently versioned plugin**, so
you install and update exactly what you need.

The emphasis is on **self-learning** tooling — skills that get better at _your_ repository over time.
A `CLAUDE.md` that prunes and graduates its own decisions. A delivery crew that re-tiers its roles from
run history. A screenshot audit whose checklist tightens every time a defect slips past it.

image::https://raw.githubusercontent.com/alexmond/alexmskills/main/plugins/progress-channel/demo/demo-claude-hero.gif[Recording of a real Claude Code session: Claude starts a Maven build, and the build's live progress bar and learned time-left appear in the session's status line,width=100%]

_A real Claude Code session, recorded: xref:progress-channel.adoc[progress-channel] showing a build's live bar in the status line._

[source,text]
----
/plugin marketplace add alexmond/alexmskills
----

Then install what you want — xref:getting-started.adoc[Getting Started] has the full list.

== Self-learning

Skills that accumulate knowledge about the repo they run in. State lives in the consuming repo's
`.claude/`, never in the plugin, so what they learn survives an update.

[cols="1,3",options="header"]
|===
| Plugin | What it does

| xref:evolving-claude-md.adoc[evolving-claude-md]
| Turns CLAUDE.md into a living Decisions & Learnings log that prunes, graduates, and archives itself — six hooks keep it honest, and `/evolving-claude-md:compact` cleans it up in one reviewed edit.

| xref:memory-hygiene.adoc[memory-hygiene]
| Keeps agent-written memory files from rotting — re-verifies version pins, sequence facts, and cited paths against the tree; flags what became wrong, never deletes.

| xref:prompt-coach.adoc[prompt-coach]
| Reads every prompt you send and rewrites it toward better prompting habits — 42 rules across 6 tiers, mastery earned by demonstration, adaptive precision-gating, and a local web dashboard.

| xref:roles.adoc[roles]
| The shared substrate: a per-repo registry of evolving personas (`.claude/roles/`) usable solo, or as crew roles, panel seats, and sweep coverage angles.

| xref:dev-crew.adoc[dev-crew]
| Composes a task-fit roster and runs it as a gated delivery relay, each role a subagent on its own model tier.

| xref:brainstorm-panel.adoc[brainstorm-panel]
| Assembles a task-fit panel of role-specialized agents, picks a coordination style, and runs a generate-critique-refine loop with a unanimity guard.

| xref:screenshot-sweep.adoc[screenshot-sweep]
| Reads the whole screenshot, not just the bug you came for. Its defect checklist tightens each time something slips past it.

| xref:skill-linter.adoc[skill-linter]
| Audits `SKILL.md` files against published authoring guidance — every rule cited. Learns from its own misses and false positives.

| xref:learn-on-failure.adoc[learn-on-failure]
| Auto-saves a durable learning to project memory whenever a task takes more than one fix cycle.

| xref:conductor.adoc[conductor]
| The runtime half of multi-lane orchestration: four measured lane-deviation shapes, relay/re-scope/pause routing, verdict-reading rules, a measured parallelism ceiling — with per-repo learnings that graduate into the role substrate.
|===

== Workflow

Guided procedures for a specific job, start to finish.

[cols="1,3",options="header"]
|===
| Plugin | What it does

| xref:mindmap-prompt.adoc[mindmap-prompt]
| Sketch ideas on a canvas and compile the map into an organized prompt. `✦` expands any node with `claude -p` running in your repo. Saves as JSON Canvas.

| xref:implement-issue.adoc[implement-issue]
| Drives a GitHub issue from branch → implement → verify → PR with a guided workflow.

| xref:screenshot-tour.adoc[screenshot-tour]
| Discovers the aspects worth showing and captures a captioned, narrative-ordered screenshot deck of the current product.

| xref:progress-channel.adoc[progress-channel]
| One visible channel for every long-running process — nested sub-jobs with rolled-up bars and time-left, learned per-job ETAs, pre-start forecasts, and stall/orphan detection derived from each job's own history.

| xref:ticket-triage.adoc[ticket-triage]
| Backlog-drain loop: rank the open tickets, dispatch the startable ones in parallel (worktree-isolated, role-briefed, honest width), verify, merge, and re-triage on every completion.

| xref:maven-quality.adoc[maven-quality]
| Format, static-analysis, coverage, and pre-commit skills for Maven/Java projects.

| xref:security-audit.adoc[security-audit]
| Scans a codebase for OWASP-style vulnerabilities and reports them with remediation.
|===

== Four of these are one system

`roles`, `dev-crew`, `brainstorm-panel` and `research-sweep` share a substrate of evolving personas.
One `skeptic` behaves the same whether it runs solo, sits on a panel, or verifies a research finding —
and accumulates what it learns along the way. The three orchestrators chain: research **discovers**,
the panel **decides**, the crew **delivers**.

Full model: xref:role-system.adoc[The Role System].
